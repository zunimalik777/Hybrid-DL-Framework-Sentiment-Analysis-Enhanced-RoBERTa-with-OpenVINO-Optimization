# A Novel Hybrid Sentiment-Guided RoBERTa-Two State GRU for Efficient Sentiment Analysis with OpenVINO Optimization
# Abstract 
This repository implements a sentiment classification framework integrating Sentiment-Guided Contextual–Semantic Fusion (SG-CSF) and Sentiment-Guided Two-State GRU (SG-TSGRU). The model combines RoBERTa contextual representations, Word2Vec semantic embeddings, and VADER sentiment features through adaptive feature fusion and sentiment-guided recurrent processing. A Sentiment-Preserving Semantic Augmentation (SP-SA) strategy increases training-data diversity while constraining semantic and sentiment changes. The framework supports evaluation on IMDb and Sentiment140, with optional ONNX and OpenVINO deployment for investigating the trade-off between classification performance and inference efficiency.
# Introduction
Conventional sentiment classification models may struggle with lexical variation, context-dependent sentiment, and sequential dependencies. The proposed SG-CSF–SG-TSGRU framework addresses these challenges by adaptively integrating contextual, semantic, and lexicon-derived sentiment information. SG-CSF performs gated feature fusion, while SG-TSGRU incorporates sentiment features into forward and backward recurrent-state computation. Attention-based pooling generates the final sequence representation for binary sentiment classification. The implementation also supports training-only SP-SA, reproducible experiments, cross-dataset evaluation, and model export. This tutorial introduces how to train optimized novel hybrid model for sentiment analysis. # Architecture implemented
- Contextual branch: FacebookAI/roberta-base token-level hidden states.
- Semantic branch: CBOW Word2Vec vectors trained only on the original training partition. Each word vector is aligned to RoBERTa's subword positions using a fast tokenizer's word_ids() mapping.
- VADER branch: [positive, negative, neutral, compound] features computed from minimally modified raw text, then broadcast across the sequence for the model's sentiment-guided operations.
- SG-CSF: token-wise learned gate for contextual/semantic fusion, followed by VADER-conditioned modulation and layer normalization.
- SG-TSGRU: forward and backward recurrent paths with sentiment features entering reset, update, and candidate gates; a learned directional attention combines the states.
- Pooling and prediction: masked token-attention pooling and a two-class softmax classifier.
- SP-SA: augmentation is applied to training samples only. A candidate replacement must meet both Word2Vec cosine-similarity and VADER compound-score consistency thresholds. Validation/test text is not augmented
